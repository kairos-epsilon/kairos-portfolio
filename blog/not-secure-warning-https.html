「保護されていない通信」と表示されたら｜運営者向けの確認

公開：2026年10月31日

自社のホームページを開いたら、アドレスの横に、「保護されていない通信」と出ていた。お客様から、「サイトに警告が出ている」と言われた。そんなときに確認したいことを、運営者の立場から整理します。

この表示は、何を意味しているのか

ブラウザ（Google Chrome など）は、https:// で始まらないページ、つまり、通信が暗号化されていないページに、「保護されていない通信」といった表示を出します。トレンドマイクロなどの解説によると、Chrome は、2018年7月ごろ（Chrome 68）から、https でないページに、こうした表示を出すようになりました。目的は、訪れた人に注意を促すことと、サイトの運営者に、https 化を促すことです。

通信が暗号化されていないと、ページの内容や、フォームに入力した情報が、途中で見られたり、書き換えられたりするおそれがあります。

運営者が確認すること

  • アドレスが https:// で始まっているか：ブラウザに表示されるアドレスが、http:// で始まっていないかを見ます。http:// の場合は、https 化が必要です。
  • 証明書（SSL 証明書）の有効期限は切れていないか：有効期限が切れると、ブラウザが警告を出すことがあります。サーバー会社の管理画面で、期限と、自動更新の設定を確認します。
  • https のページの中に、http のものが混ざっていないか：https のページでも、画像やスクリプトなどが、http のまま読み込まれていると、警告が出ることがあります。制作会社に確認します。
  • http:// で開いたとき、https:// に自動で切り替わるか：古いアドレスから来た人が、安全でないほうに入らないよう、自動の切り替え（転送）を設定します。

https 化の進め方

  • 1. サーバー会社で、SSL 証明書を設定する：多くのサーバー会社が、無料の証明書の設定を用意しています。
  • 2. サイトのアドレスを、https:// に切り替える：WordPress などでは、サイトのアドレスの設定も変更します。
  • 3. http から https への転送を設定する：古いアドレスで開いても、https に切り替わるようにします。
  • 4. 表示を確認する：全部のページで、警告が出ないか、フォームが動くかを確認します。

設定を誤ると、サイトが表示されなくなることもあります。作業の前には、バックアップを取り、制作会社やサーバー会社に相談しながら進めるのが安全です。

警告は、「信頼」の問題でもある

お客様は、警告が出ているサイトに、問い合わせの情報を入力することを、ためらいます。お問い合わせフォームのあるサイトでは、問い合わせが減ることにもつながります。警告が出たまま放置せず、早めに対応することをおすすめします。

ほかの守りも、あわせて確認する

https 化は、ホームページの「守り」の一部です。更新、パスワード、バックアップなど、ほかの点も確認したい方は、ホームページのセキュリティ セルフチェック（無料・3分）をお使いください。入力した内容は、端末の中だけで処理され、送信されません。2026年10月に公表された PHP の脆弱性については、PHP2shell とは？何が問題で、何をすればいい？で解説しています。

Kairos では、SSL 証明書の設定や更新の確認を含む、公開後の保守・運用に対応しています（保守プラン ライト 月5,000円〜／税込、最低契約6か月）。「自分で設定するのは難しい」という方も、ご相談ください。ヒアリングは無料です。蟹江町や近隣の方は、対面でも相談できます（蟹江町のホームページ制作）。

この記事は、2026年10月31日時点の情報にもとづきます。ブラウザの表示や、仕様は変わることがありますので、最新の内容は、出典などでご確認ください。

FAQ

よくあるご質問

「保護されていない通信」と出ると、サイトが乗っ取られているのですか？

必ずしもそうではありません。この表示は、そのページの通信が暗号化されていない（アドレスが http:// で始まる）ことなどを知らせるものです。ただし、お客様が不安になる表示なので、早めに対応することをおすすめします。

https にするには、何をすればよいですか？

サーバー会社で、SSL 証明書を設定し、アドレスを https:// で表示できるようにします。多くのサーバー会社が、無料の証明書の設定を用意しています。制作会社やサーバー会社に相談してください。

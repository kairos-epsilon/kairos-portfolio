2026年10月、PHP というプログラムに、重大な脆弱性（弱点）が見つかりました。「PHP2shell」と呼ばれています。WordPress など、PHP で動くホームページを持っている方は、確認が必要です。この記事では、IPA（情報処理推進機構）と PHP の公式サイトの情報をもとに、何が問題なのか、何をすればよいのかを、できるだけやさしく整理します。

PHP2shell とは何か

PHP2shell は、PHP の2件の脆弱性（CVE-2026-109618 と CVE-2026-109619）を組み合わせたものを指す通称です。PHP の公式サイトによると、どちらも、ログインなどの認証をしなくても、遠隔からサーバー上でプログラムを実行できてしまう（リモートコード実行）可能性がある、重大な脆弱性です。

  • CVE-2026-109618：メモリが足りなくなったときの処理の途中で、内部のデータが一部しか初期化されず、あとの処理が不正なデータを有効なものとして扱ってしまう問題
  • CVE-2026-109619：リクエストに結び付いた内部の状態が、メモリが解放されたあとも残り、後続のリクエストが、その古い状態を使ってしまう可能性がある問題

専門的な内容ですが、ポイントは1つです。条件がそろうと、見ず知らずの第三者が、サーバーの中で、勝手にプログラムを動かせてしまうおそれがある、ということです。

何が問題なのか

サーバーの中で、他人にプログラムを動かされると、ホームページの改ざん、情報の盗み出し、ほかの攻撃の踏み台にされる、といった被害につながるおそれがあります。

IPA の注意喚起によると、2026年10月26日（現地時間）に、米国の CISA（サイバーセキュリティ・インフラストラクチャセキュリティ庁）の、悪用が確認された脆弱性の一覧（KEV カタログ）に、この脆弱性が掲載されました。一方、IPA は、国内での被害事例は把握していないとしています（2026年10月27日の更新時点）。

どのバージョンが対象で、修正版はどれか

IPA によると、次のバージョンより前の版が対象です。修正版は、各系統の最新版です。

PHP の系統修正版（この版以降）
8.2 系8.2.35
8.3 系8.3.36
8.4 系8.4.27
8.5 系8.5.12

修正版は、2026年10月21日に公開されました。いまお使いの PHP のバージョンが、上の表の修正版より古い場合は、更新が必要です。

PHP 8.1 以前を使っている場合

PHP 8.1 以前は、すでにサポートが終了しており、PHP のプロジェクトからは、更新が提供されません。次の点に注意してください。

  • Linux の配布元や、長期サポートを提供する事業者が、独自に対策した版を出している場合があります。その場合は、バージョンの表示が古くても、対策が済んでいることがあります。サーバー会社に確認してください。
  • 確認できない場合や、対策がない場合は、サポートされている版（8.2 〜 8.5）への移行を検討してください。
  • WordPress のテーマやプラグインが、新しい PHP に対応していないことがあります。バックアップを取り、確認してから移行します。

PHP 8.2 を使っている方へ：年末にサポートが終わります

PHP の公式サイトによると、PHP 8.2 のセキュリティサポートは、2026年12月31日に終了します。修正版（8.2.35）に更新しても、年が明けると、新しい更新は出なくなります。8.3 は2027年12月31日、8.4 は2028年12月31日、8.5 は2029年12月31日までです。計画的に、新しい版への移行を進めることをおすすめします。

いま、やること

  • PHP のバージョンを確認する：制作会社やサーバー会社に聞くのが確実です。WordPress なら、管理画面の「ツール」→「サイトヘルス」→「情報」→「サーバー」で見られます。
  • 修正版より古ければ、更新を依頼する：更新の前には、バックアップを取ります。
  • すぐに更新できない場合：IPA の注意喚起に書かれた緩和策を確認し、アクセス制限などの暫定対策を、サーバー会社に相談します。PHP の公式サイトは、更新が唯一の完全な対策であり、緩和策は、攻撃の経路を減らすだけで、安全にはならないとしています。
  • ほかの部分も確認する：WordPress 本体、テーマ、プラグインも、最新にしておきます。

バージョンの判定は、PHPバージョン診断（無料）でも、すぐに確認できます。ホームページ全体の「守り」を確認したい方は、セキュリティのセルフチェックをお使いください。基本の考え方は、ホームページのセキュリティ、何を確認すればいい？でも解説しています。

自分で対応するのが難しいとき

PHP の更新は、サーバーの設定にかかわるため、ふだんホームページを管理していない方には、難しい作業です。Kairos では、更新や点検を継続してお任せいただく保守プランを用意しています（ライト 月5,000円〜、スタンダード 月15,000円〜、システム保守 月30,000円〜／税込、最低契約6か月）。お客様のサイトの構成によって、確認することが変わりますので、まずはご相談ください。ヒアリングは無料です。蟹江町や近隣の方は、対面でのご相談もできます（蟹江町のホームページ制作）。
